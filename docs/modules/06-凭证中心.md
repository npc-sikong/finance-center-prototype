# 凭证中心功能需求说明

## 模块目标

凭证中心用于展示凭证批次、正式借贷分录和信用台账信用行，帮助使用方检查每笔业务是否借贷平衡、信用类是否独立展示、冲正是否可追踪。

## 当前功能范围

- 展示凭证批次列表：凭证号、规则 ID、业务名称、模板编码、业务源表、业务单号、补记账本、核销键、幂等键、矩阵动作、缺口编号、状态、借方、贷方、信用台账、入账时间。
- 展示选中凭证的借方、贷方、信用台账和差异指标。
- 展示记账凭证纸预览。
- 展示选中凭证明细行，明细行包含业务源单、补记账本、核销键、幂等键、矩阵动作和缺口编号。
- 承接账本中心的“凭证下钻”：账本中心只展示资金影响，凭证批次和凭证明细在本页作为做账证据查看。
- 支持查看凭证、查看详情、红字冲正、导出凭证。

## 主要操作

- 点击“查看”切换右侧选中凭证。
- 从账本中心点击“凭证下钻”时，进入本页并按凭证号过滤凭证批次和分录明细。
- 点击“详情”打开凭证批次完整字段。
- 对已入账凭证点击“红字冲正”，生成反向凭证并将原凭证标记为已冲正。
- 点击明细行“详情”查看单行分录字段。

## 数据与口径

- 正式分录参与借贷平衡。
- 信用台账信用行不参与借贷平衡，只作为信用金额展示。
- 红字冲正对正式分录交换借贷方向，对信用行反转增加/减少方向。
- 凭证状态包括已入账、已冲正、冲正凭证、预览等演示状态。
- 矩阵动作、覆盖程度和补记说明来自资金账变动作影响数据。
- `动作总览` 负责说明凭证关联的业务动作，`资金影响明细` 负责说明该动作影响到哪些资金模块，`缺口与待确认` 负责说明凭证或账本仍需补齐的事项。
- 本次闭环补齐的模板要求每个凭证批次可追踪 `source_table + source_id + template_code`，用于拦截重复做账并联动账本和核销状态。
- 官方现金收付必须关联 `official_account_record`；自动扣额度和信用变动不得冒充现金收款。
- 本页展示的是演示凭证批次，不代表真实凭证引擎已上线。

## 验收要点

- 每张已入账凭证应能看出借方、贷方、信用台账和差异。
- 红字冲正后应生成新凭证号，并在原凭证记录上保留冲正关系。
- 凭证明细中的科目编码应跟随科目编码维护同步变化。
- 点开凭证详情必须能看到矩阵动作、覆盖程度、缺口编号和补记说明。
- 点开凭证详情必须能看到业务源单、补记账本、核销键和幂等键。
