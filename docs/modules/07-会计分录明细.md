# 会计分录报表功能需求说明

## 模块目标

会计分录报表是凭证、账本和报表的下钻页，用于按每笔资金账变查看分录记账结果、借贷状态、对应账本和信用台账影响；逐行分录不在主页面重复铺开，统一放入“凭证详情”抽屉中查看。

## 细分说明

- 凭证汇总：一行业务凭证展示来源单号、业务类型、模板编码、凭证号和后端覆盖状态。
- 分录步骤：显示该凭证包含的步骤数量、正式分录行数和信用台账行数。
- 借贷状态：按当前筛选重算借方金额、贷方金额、信用台账金额和借贷差。
- 对应账本：展示凭证影响的补记账本和核销关系，方便从凭证追到账本。
- 凭证详情：完整分录行放入详情抽屉，主表不重复铺开技术明细。

## 当前功能范围

- 展示分录步骤、正式分录行、信用台账行、借方发生额、贷方发生额、借贷差。
- 不作为左侧一级导航入口，避免财务用户先看技术明细而不是账本和报表结果。
- 展示每笔业务凭证结果，包含业务时间、源业务单号、业务类型、凭证号、模板编码、分录步骤、借贷状态、对应账本、核销关系和后端覆盖状态。
- 提供页面级下拉筛选：业务类型、站点、发起主体身份、发起主体、凭证号、模板编码、借贷状态、对应账本、核销关系、后端覆盖。
- 凭证详情弹窗只展示“分录行”内容，不再展示凭证号、规则、来源、金额汇总等其它字段。
- 支持查看凭证详情和导出会计分录报表。

## 主要操作

- 汇总表中的“凭证详情”打开对应凭证批次。
- 从账本中心或财务统计点击凭证号时，进入本页并按凭证号过滤业务凭证汇总。
- 选择分录筛选项后，分录步骤、正式分录、信用台账、借方发生额、贷方发生额和借贷差指标同步按当前筛选重算。
- 点击“清空筛选”恢复全部凭证汇总。
- 在凭证详情抽屉中查看正式借贷行、信用台账行、金额表达式和关系说明。

## 数据与口径

- 正式分录行根据方向拆分为借方金额和贷方金额。
- 信用台账行显示信用金额，不进入正式借贷平衡。
- 分录关系字段说明当前行对应的另一侧科目；信用行说明其不参与借贷平衡。
- 业务凭证汇总按凭证号聚合正式行、信用行、借方、贷方、信用金额和涉及科目。
- 分录筛选项来自当前凭证汇总表字段，优先使用下拉选择；导出会计分录报表时只导出当前筛选结果。
- 矩阵字段从凭证批次和分录行继承，便于从分录追溯到资金账变动作、影响模块和底层补齐资料。
- `动作总览`、`资金影响明细`、`资金模块字典`、`缺口与待确认` 四张新表共同决定分录的业务动作、资金模块、科目边界和待补说明。
- 本次补齐后，现金收款、现金出款、三方清算、提现待付、红包、预付外部资产、奖励成本、月结收款、场馆付款、游戏投注/派奖等分录可追踪到对应业务源单。
- 900xxx 和非正式行只作为信用台账行展示，不进入正式借贷平衡。
- 本页补齐的是原型分录明细字段，不代表真实总账明细表已完成后端落地。

## 验收要点

- 当前筛选下借贷差应随全局搜索和表内搜索实时变化。
- 当前筛选下借贷差应随页面级下拉筛选、全局搜索和表内搜索实时变化。
- 正式分录和信用台账数量应与凭证批次明细一致。
- 主页面不再展示“分录逐行明细”面板，避免与凭证详情重复。
- 列表中的“分录步骤”应展示该凭证包含的步骤数量。
- 凭证详情弹窗正文只能显示“分录行”表格。
- 凭证详情中的分录行应能看到方向、科目、金额表达式和关系说明。
