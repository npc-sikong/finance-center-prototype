# 核销对账功能需求说明

## 模块目标

核销对账用于证明业务源单、凭证、账本和清算关系已经对上，帮助财务按主体、源单、凭证和账本定位未核销、差异或待确认记录。

## 当前功能范围

- 展示核销记录、已串凭证账本、待处理/差异、差异金额等指标。
- 主表展示更新时间、核销对象、业务单号、站点ID、站点名称、发起主体类型、发起主体ID、发起主体名称、代理ID/名称、会员ID/名称、来源单据、核销关系、金额、差异、核销状态、凭证号、关联账本、后端落账状态和财务处理建议。
- 提供页面级下拉筛选：核销对象、来源单据、站点、发起主体类型、发起主体、核销关系、核销状态、凭证号、关联账本、后端落账状态。
- 支持查看核销详情、查看关联凭证、导出核销对账。

## 主要操作

- 选择下拉筛选项后，指标、主表和导出结果同步刷新。
- 点击“清空筛选”恢复全部核销记录。
- 点击“详情”查看核销记录完整字段。
- 点击“凭证”下钻到对应凭证详情。

## 数据与口径

- 筛选项来自当前核销对账表字段，优先使用下拉选择，不依赖自由输入。
- 核销状态、后端落账状态和差异金额只作为原型核对口径，不代表真实清算程序已完成。
- 主体名称和ID为静态原型稳定演示归属；真实后端需在核销记录中落站点、代理、会员归属字段。
- 导出核销对账时只导出当前筛选结果和当前筛选条件。

## 验收要点

- 按核销状态筛选时，待核销、部分清算、差异复核等记录数量和差异金额应同步变化。
- 按站点或发起主体筛选时，主表只能展示对应主体链路的记录。
- 导出结果必须与当前页面筛选一致。
