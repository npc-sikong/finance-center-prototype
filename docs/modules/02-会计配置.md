# 会计配置功能需求说明

## 模块目标

会计配置用于维护平台资金账变入账所需的最小会计规则，供财务确认科目、科目编码、会计模板、会计分录和凭证生成规则。

## 细分说明

- 会计科目表：查看资产、负债、收入、成本和信用类科目，以及辅助核算维度。
- 科目编码：只演示编码调整，科目名称和科目含义保持锁定。
- 会计模板：按业务事件维护入账模板，并在详情中维护分录步骤。
- 会计分录：定义每个模板的借方、贷方、信用台账、金额公式和来源字段。
- 凭证生成规则：说明业务动作如何生成凭证，哪些正式制证，哪些只做来源或信用追踪。

## 当前功能范围

- 只保留 5 个生产必需页签：会计科目表、科目编码、会计模板、会计分录、凭证生成规则。
- 会计模板定义资金账变业务场景和金额口径。
- 会计分录定义模板对应的借方、贷方和信用台账行。
- 进入会计配置默认显示“会计模板”列表，主列表优先展示中文业务名称、模板编码、金额表达式和会计步骤说明。
- 会计模板主列表不展示 `覆盖状态`、`补记建议` 这类补缺口评审字段；这些字段只在详情抽屉中作为追溯信息保留。
- 点击模板列表的“详情”后弹出模板详情抽屉，并在抽屉中通过内嵌“编辑步骤”面板增加、删除、复制或编辑该模板下的会计分录行。
- 每个分录行只允许通过下拉选项维护，字段包括分录步骤号、分录性质、来源/源表、来源字段、分录组、影响模块、账本/账户、对象、科目类型、借贷/控制方向、金额公式、具体行为、余额影响、更新账户流水、进入报表、余额更新状态和备注。
- 分录编辑不提供自由输入、备注文本框或高级 JSON；下拉选项只来自当前已有业务数据、会计科目、模板、分录、源表、源字段、金额变量、主体、账本和方向口径。
- 保存分录行调整后，原型会重建演示凭证批次、凭证详情分录和报表汇总，并写入浏览器本地状态。
- 凭证生成规则定义业务账变如何生成凭证批次，并标明规则性质、是否正式制证、借方行、贷方行、信用台账行和规则展开方式。
- 资金影响模块、核销键、幂等键、后端缺口和状态机资料不再作为会计配置主页签展示；这些内容保留在账本中心、凭证详情、财务统计或底层数据中追踪。
- 每张表展示当前配置的主要字段，并通过详情抽屉查看完整字段。
- 支持表内搜索、全局搜索、排序、分页。
- 支持导出当前配置表。

## 主要操作

- 点击页签切换 5 个必需配置表。
- 点击“详情”查看某条配置的完整字段和值。
- 点击“导出当前表”导出当前页签对应的配置数据。

## 数据与口径

- 配置数据直接来自 `assets/finance-data.js`。
- v11 基础会计配置已按现有业务复核：40 个科目、87 个模板、220 条分录、39 条规则。
- 会计模板和会计分录的调整会保存在 `financeCenterDemoState.v14`，包含模板、分录行、凭证规则、凭证批次、账本记录和核销追踪状态。
- 资金影响模块统一在“账本中心”按会计审核账本查看；业务映射、幂等关联、账户主档、凭证源等技术资料不进入会计配置主操作区。
- 会计科目表区分资产、负债、收入、成本、信用类，并补充辅助核算维度和生产控制要求。
- 会计分录中 `是否正式分录=否` 或 900xxx 科目为信用台账信用行。
- 分录编辑选择 900xxx 信用科目时，系统自动按信用台账处理，并强制 `进入报表=否`，不进入正式借贷报表。
- Nexus 充值成功链路使用 `引用模板=TPL-MDEP-001` 追溯会员充值正式分录，不再把模板编码放进科目编码列。
- 充值成功模板只确认三方应收、主体余额负债和手续费代扣，三方/官方到账统一通过清算或官方账户流水核销。
- 站点/代理提现拆为申请待付、成功出款、失败回退；不在同一个模板里同时表达待付和出款。
- 站点月结应收确认和现金收款核销分离；自动扣额度和人工结算只作为信用/状态来源，不当作现金收款。
- 凭证批次通过 `sourceDoc`、`supplementLedger`、`reconciliationKey`、`idempotencyKey` 串联业务源单、账本和核销结果。
- 凭证生成规则中借方行、贷方行、信用台账行共同决定凭证预览与演示入账。
- `是否正式制证=否` 的规则只进入来源、信用或核销追踪，不进入正式借贷报表。
- “财务中心佣金结算”已补齐业务事件、模板、分录、VCH-020 规则归属和业务映射，作为佣金类聚合规则的一部分。
- 配置页只代表入账规则演示口径，不代表真实后端表已经存在；运营异常处理、外部核销执行和期间结账不属于当前会计配置模块。

## 验收要点

- 页面必须只显示 5 个必需页签：会计科目表、科目编码、会计模板、会计分录、凭证生成规则。
- 会计配置默认页签必须是“会计模板”，并默认展示全部模板列表。
- 不应在会计配置主界面显示业务事件清单、系统账变映射、动作总览、资金影响明细、缺口与待确认、闭环总控、状态机定义等评审型页签。
- 详情抽屉必须能展示主表未显示的字段。
- 导出内容必须与当前页签一致。
- 凭证生成规则必须能说明规则性质、是否正式制证、借方行、贷方行、信用台账行、幂等键和展开方式。
- 会计模板页主列表不默认展开分录行，必须点击“详情”后才在抽屉中通过内嵌步骤面板维护分录行。
- 会计模板列表必须显示“会计步骤说明”，并按该模板的分录行自动汇总借方、贷方和信用台账步骤。
- 模板详情的编辑步骤区域不得出现自由输入框、备注文本框或高级 JSON；除按钮外只能使用下拉选择。
- 保存会计分录行后，会计分录报表和财务报表必须使用调整后的分录重新计算。
