# 账本中心功能需求说明

## 模块目标

账本中心用于给财务会计审核每笔资金账变影响了哪些账本。主界面只保留资金账本和必要信用台账，支持按日期筛选、查看详情、凭证下钻、导出当前账本，并对允许冲正的账本发起冲正申请。

## 当前功能范围

- 通过“账本类型”下拉切换不同会计审核账本，避免大量账本页签占据主界面。
- 展示账变记录：业务时间、业务单号、业务类型、影响账本、站点ID、站点名称、发起主体类型、发起主体ID、发起主体名称、代理ID/名称、会员ID/名称、方向、金额、前值、后值、凭证号、核销状态、结账期间、入账口径。
- 支持按报表字段筛选：账本类型、影响主体、业务主体、业务类型、方向、核销状态、入账口径。
- 保留正式资金账本和必要信用台账：官方现金流水、三方/手续费清算、会员/代理主钱包、站点/总站余额、提现待付、红包待领、奖励成本、预付金外部付款、月结应收、场馆费应付、游戏结算、场馆钱包等。
- 信用台账在主表标记为“不进正式报表”，避免把额度、冻结、费用快照等误当现金或资产负债表科目。
- 支持日期筛选：开始日期、结束日期、清空日期。
- 支持快捷日期：1日、近3日、近7日、近1月、上月。
- 支持查看详情、凭证下钻、发起冲正申请、导出当前账本。
- 不提供任意手工造账或原始记录编辑入口，避免业务用户绕过来源单据和凭证规则改账。
- 凭证批次、凭证明细、业务映射表、做账幂等关联、现金账户主档、老佣金迁移、费用快照扩展、纯凭证源/配置源不再作为账本中心一级页签展示。

## 主要操作

- 点击快捷日期后，账变表和当前账本导出结果同步按日期范围过滤。
- 调整账本类型下拉后，主表切换到对应账本；旧账本下才存在的业务类型、方向、核销状态、入账口径筛选会自动清空。
- 输入影响主体时可按主体ID/名称、站点ID/名称、代理ID/名称、会员ID/名称搜索；选择业务主体、业务类型、方向、核销状态、入账口径后，主表和导出结果同步过滤。
- “详情”打开账本记录完整字段。
- “凭证下钻”从账本记录的凭证号进入会计分录报表页，查看凭证批次、借贷分录和信用行。
- “发起冲正申请”将记录标记为冲正待审批，后续必须通过凭证审批和外部核销复核处理。

## 数据与口径

- 账本定义来自“账本表结构设计”，但账本中心只读取其中符合会计审核口径的资金账本和必要信用台账。
- 账本记录由种子凭证、账本定义和核销链路生成，不允许从业务界面手工造账。
- 每笔账变主表只展示会计审核所需字段，模板编码、幂等键、源表、源码依据等技术字段放入详情抽屉或会计配置。
- 账本模块和增减含义来自新表 `资金模块字典`，账变记录的覆盖程度来自 `资金影响明细`。
- `动作总览` 中的 50 个账变动作会通过模板编码、业务源单和账本模块串到账本记录。
- 本次补齐新增三方通道清算、提现待付负债等账本定义，并为官方账户、红包、预付、奖励、月结、场馆、游戏等账本生成可查看的演示账本记录。
- 账本中心负责查看资金变动影响模块；会计配置只维护科目、模板、分录和凭证生成规则。
- 凭证批次和凭证明细是做账证据，不是资金账本；只能从凭证号、凭证中心或会计分录报表下钻进入。
- 业务映射、幂等关联、账户主档属于配置或审计追踪，不作为会计主账本页签。
- 日期筛选基于账变记录的更新时间或入账时间。
- 账本冲正只允许发起申请，不直接生成反向流水。
- 财务中心不执行核销；核销键只作为清算、对账或核销程序回传结果的只读追踪字段。
- 覆盖程度来自资金影响明细和底层补齐资料，可显示当前落表、原型已补齐、后端待落地、部分覆盖或信用台账。
- 账本流水使用 `source_table + source_id + template_code` 作为演示幂等关联，和凭证批次、核销结果保持同一个业务来源。
- 主体名称和ID为原型稳定演示归属，用于确认报表字段是否足够；真实后端需要在业务源单和账本流水中落站点、代理、会员归属字段后才能替换演示值。
- 本页补齐的是原型账本记录，不代表真实后端已创建 `official_account_record`、`channel_clearance_ledger`、`withdraw_payable_ledger` 等对应流水表。

## 验收要点

- 从账本看板卡片进入时，应定位到对应账本。
- 页面不展示凭证批次、凭证明细、业务映射表、做账幂等关联等系统页签。
- 页面只展示账本名称、记录数、优先级、账本类型下拉、报表字段筛选、日期筛选和会计审核账变表。
- 主表字段应为：业务时间、业务单号、业务类型、影响账本、站点ID、站点名称、发起主体类型、发起主体ID、发起主体名称、代理ID、代理名称、会员ID、会员名称、方向、金额、前值、后值、凭证号、核销状态、结账期间、入账口径。
- 快捷日期和手工日期范围必须影响账变列表和导出结果。
- 发起冲正申请后，应写入审计时间线并持久化到原型状态。
- 导出当前账本只包含当前账本模块和当前筛选条件下的会计审核字段。
- 点开账本详情必须能看到业务源单、补记账本、核销键和幂等键。
- 点击凭证下钻必须能进入凭证批次和凭证明细。
- 需要核对资金影响模块时，应能通过账本中心定位补齐项；需要看科目、模板、分录或凭证规则时，应回到会计配置。
