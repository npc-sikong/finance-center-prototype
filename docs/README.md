# 财务中心演示后台功能总说明

## 目标

财务中心演示后台是一个本地静态原型，用于按生产财务中心口径检查平台资金账变入账、影响账本、凭证分录、财务统计和财务报表。

## 数据来源

- 页面入口：`财务中心运营后台演示版.html`。
- 演示数据：`assets/finance-data.js` 中的会计科目、会计模板、会计分录、凭证生成规则、资金影响参考数据和种子账本记录。
- 账变影响数据来源：`/Users/sikon/Documents/heiheihei/outputs/account-change-fund-impact/账变动作资金影响矩阵.xlsx`。
- 新表已导入：`动作总览` 50 条、`资金影响明细` 177 条、`资金模块字典` 24 条、`缺口与待确认` 15 条；缺口与闭环类数据只作为规则追踪和后续实施依据，不作为生产前台模块。
- 入账闭环：平台资金账变通过凭证生成规则形成凭证批次和分录，并在账本中心按会计审核口径记录影响账本、方向、金额、前后余额、凭证号、核销状态和结账期间；模板编码、幂等键等技术字段放入详情、凭证中心或会计配置。
- 运行状态：浏览器 `localStorage`，键名为 `financeCenterDemoState.v14`；旧 v13/v12/v11/v10/v9/v8/v7/v6/v5 状态会迁移，种子凭证、账本和核销追踪记录按当前入账口径重建。
- 核心口径：正式分录只纳入资产、负债、收入、成本；900xxx 信用类作为信用台账独立展示，不参与正式借贷平衡。
- v11 配置维护：会计模板页支持按模板增加、删除、复制和编辑会计分录行；每行的行号、方向、科目、金额表达式、正式分录标识、源表和备注等参数都可由会计调整。
- 会计配置默认进入会计模板列表，列表先展示中文业务名称；点击模板“详情”后才弹出分录行维护抽屉。
- 生产前台不展示“业务闭环”模块组；运营异常处理、外部核销执行和期间结账流程由其它系统或后续后台承担，本原型只保留核销键、幂等键和账本影响统计。
- 原型边界：本原型补齐的是业务看板、会计模板、分录、账本、核销、报表和说明，不代表真实后端已经落表或完成数据库迁移；清算、对账、核销执行由外部程序完成，本后台只保留核销键用于统计追踪。

## 新表说明

- `动作总览`：按业务动作汇总当前落表影响、应补影响、覆盖程度和关联模板，用于判断每类平台资金账变是否有入账入口。
- `资金影响明细`：按动作拆到主体、资金模块、表字段、方向和金额口径，用于账本中心判断每笔账变影响到哪些资金账本。
- `资金模块字典`：定义官方账户、三方通道、会员余额、站点余额、预付金、红包、场馆钱包、月结、信用台账等模块的资金性质和增减含义。
- `缺口与待确认`：保留现金账户、三方清算、提现待付、红包待领、预付资产、奖励成本、月结现金、场馆费、游戏结算、幂等关联等真实后端落地差距及优先级。

## 全局交互

- 左侧导航按生产财务统计路径展示：总览、账本、报表、配置。
- 顶部只保留全局搜索、优先级筛选和状态筛选；不提供重置原型数据、任意手工造账或原始记录编辑入口。
- 所有表格支持表内搜索、排序、分页和详情抽屉。
- 导出按钮只输出当前模块或当前视图对应的列表数据。
- 业务资金明细、会计分录报表和核销对账均提供页面级筛选，筛选项优先使用下拉选择，并来自当前表格字段；导出结果跟随当前筛选条件。
- 账本中心服务会计审核，不作为系统表浏览器；账本类型使用下拉选择，影响主体、业务主体、业务类型、方向、核销状态和入账口径支持筛选；凭证批次、凭证明细、业务映射、幂等关联和账户主档从凭证中心、会计配置或详情下钻查看。
- 各模块文档需要说明页面功能、数据来源、入账口径、导出口径和本次根据新表补齐的内容。
- 页面功能更新后，必须同步更新本目录下的总说明和对应模块说明。
