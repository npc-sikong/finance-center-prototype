# 财务中心记账工作台演示版

这是一个静态 HTML 原型，用于展示财务中心的资金账变、账本中心、会计分录报表、核销对账、财务统计和财务报表页面。

## 在线访问

发布到 GitHub Pages 后，直接打开仓库 Pages 地址即可访问。根目录的 `index.html` 会自动跳转到演示版入口。

## 本地预览

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8765/
```

## 入口文件

- `index.html`
- `财务中心运营后台演示版.html`

## 说明

本项目为静态原型，不包含后端服务和生产数据库迁移。
